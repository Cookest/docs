# Welcome to Cookest

Cookest is a full-stack AI-assisted meal planning and kitchen management platform built as a school project (PAP). It helps users plan weekly meals, manage their pantry, generate shopping lists, and get AI-powered cooking advice.

## Project components

| Component | Technology | Purpose |
|-----------|-----------|---------|
| **API** | Rust · Actix-Web 4 · SeaORM · PostgreSQL | REST backend |
| **Mobile App** | Flutter · Dart · Riverpod | iOS & Android client |
| **ETL Pipeline** | Python | Data ingestion & processing |
