# Cookest

<Callout type="warn">
Esta traducción es proporcionada por la comunidad y puede no estar completamente actualizada. Para la documentación completa, consulte la [versión en inglés](/docs).
</Callout>

Cookest es una plataforma completa de planificación de comidas y gestión de cocina, construida como proyecto escolar (PAP). El backend ahora se divide en una Food API para los datos de catálogo y una App API para los flujos autenticados, una aplicación Flutter funciona en iOS y Android, y un pipeline en Python alimenta la base de datos de recetas e ingredientes.
