# Cookest

<Callout type="warn">
Diese Übersetzung wurde von der Community erstellt und ist möglicherweise nicht vollständig aktuell. Die vollständige Dokumentation finden Sie in der [englischen Version](/docs).
</Callout>

Cookest ist eine Full-Stack-Plattform für Mahlzeitenplanung und Küchenverwaltung, die als Schulprojekt (PAP) entwickelt wurde. Das Backend ist jetzt in eine Food API für Katalogdaten und eine App API für authentifizierte Abläufe aufgeteilt, eine Flutter-App läuft auf iOS und Android, und eine Python-Pipeline befüllt die Rezept- und Zutatendatenbank.
