# Bem-vindo ao Cookest

O Cookest é uma plataforma completa de planeamento de refeições e gestão de cozinha com inteligência artificial, desenvolvida como projeto de escola (PAP). Ajuda os utilizadores a planear refeições semanais, gerir a despensa, gerar listas de compras e obter conselhos de culinária por IA.

## Componentes do projeto

| Componente | Tecnologia | Finalidade |
|-----------|-----------|---------|
| **API** | Rust · Actix-Web 4 · SeaORM · PostgreSQL | Backend REST |
| **Aplicação Móvel** | Flutter · Dart · Riverpod | Cliente iOS e Android |
| **Pipeline ETL** | Python | Ingestão e processamento de dados |
