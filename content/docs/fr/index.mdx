# Cookest

<Callout type="warn">
Cette traduction est fournie par la communauté et peut ne pas être entièrement à jour. Pour la documentation complète, consultez la [version anglaise](/docs).
</Callout>

Cookest est une plateforme complète de planification de repas et de gestion de cuisine, construite comme projet scolaire (PAP). Une API REST en Rust gère tout le backend, une application Flutter fonctionne sur iOS et Android, et un pipeline Python alimente la base de données de recettes et d'ingrédients.
